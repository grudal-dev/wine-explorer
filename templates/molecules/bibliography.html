{% translate "Comment une molécule est rattachée à un vin" %}

{% translate "Nos fiches décrivent des" %} {% translate "profils types" %}{% translate ", pas des bouteilles analysées. Le lien vin → molécule est donc" %} {% translate "déduit" %} {% translate "par des règles explicites, chacune adossée à une référence :" %}

  • {% translate "Marqueur du cépage" %} {% translate ": le cépage représente au moins 15 % de l'encépagement et la littérature l'associe à la molécule (rotundone de la Syrah, thiols du Sauvignon, oxyde de rose du Gewurztraminer…)." %}
  • {% translate "Style de vinification" %} {% translate ": le sotolon des vins jaunes, la γ-nonalactone des liquoreux botrytisés." %}
  • {% translate "Couleur" %} {% translate ": le diacétyle de la fermentation malolactique, presque systématique en rouge." %}
  • {% translate "Descripteur du nez" %} {% translate ": le profil cite un arôme classiquement attribué à la molécule (vanille et vanilline, violette et β-ionone). C'est le lien le plus hypothétique : il ne dépasse jamais « probable »." %}
  • {% translate "Socle commun" %} {% translate ": quelques esters et alcools de fermentation présents dans tous les vins. Ils sont masqués par défaut dans le graphe." %}

{% translate "Chaque lien reçoit une force de 1 à 3 (plausible, probable, marqueur établi) : la plus élevée de ses justifications. Toutes les justifications restent affichées, avec leur source." %}

{% translate "Les éléments naturels" %}

{% translate "Une molécule n'est reliée à une plante, un fruit, une épice ou un aliment que si une étude l'y a identifiée. Certaines n'existent guère qu'en bouteille, comme le TDN des vieux Rieslings ou le benzèneméthanethiol du silex : elles restent sans lien naturel plutôt que d'en inventer un." %}

{% translate "Limites" %}

{% translate "Les seuils de perception sont indicatifs : ils varient selon le vin, la méthode et le dégustateur. Une molécule présente sous son seuil peut quand même jouer, en renforçant ou en masquant ses voisines. Les structures sont dessinées sans stéréochimie, et la formule brute est calculée à partir de la structure." %}
